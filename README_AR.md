# My AI World — مشروع البداية

موقع تجريبي للدردشة مع شخصيات خيالية، بواجهة عربية وإنجليزية وتصميم برغندي داكن.

## تشغيله على جهازك

1. ثبّتي Python 3.11 أو أحدث.
2. افتحي مجلد المشروع في الطرفية.
3. نفّذي: `pip install -r requirements.txt`
4. عيّني متغيرات البيئة:
   - `FLASK_SECRET`: قيمة عشوائية طويلة.
   - `SITE_PASSWORD`: كلمة المرور التي تختارينها للموقع.
   - `GEMINI_API_KEY`: مفتاح Gemini API.
5. شغّلي: `python app.py`
6. افتحي `http://127.0.0.1:5000`

على Windows PowerShell يمكن تعيين المتغيرات مؤقتًا بهذه الصيغة:
`$env:SITE_PASSWORD="اختاري-كلمة-مرور"`
`$env:FLASK_SECRET="قيمة-عشوائية-طويلة"`
`$env:GEMINI_API_KEY="ضعي-المفتاح-هنا"`

## الذكاء الاصطناعي

الدردشة تحتاج مفتاح Gemini API في متغير البيئة `GEMINI_API_KEY`. لا تضعي المفتاح في ملفات HTML أو JavaScript، ولا ترفعيه إلى GitHub. لا تفعّلي الفوترة أو تضيفي بطاقة إذا كان هدفك استخدام المجاني فقط؛ قد تتغير حدود الاستخدام المجاني.

## النشر

ملف `render.yaml` إعداد مبدئي للنشر على Render. اربطي مستودع GitHub بالمشروع، ثم أضيفي متغيرات البيئة في لوحة الخدمة. الخطة المجانية قد تتوقف مؤقتًا عند عدم الاستخدام، وحدود الخدمات تتغير.

## ملاحظات مهمة

- هذه نسخة بداية وليست موقعًا منشورًا بالفعل.
- لا توجد قاعدة بيانات دائمة بعد؛ سجل المحادثة الحالي موجود في جلسة الصفحة فقط.
- الشخصيات الحالية تجريبية وثابتة، ولا توجد لوحة إدارة لإضافة شخصيات جديدة حتى الآن.
- احتفظي بكلمة المرور ومفتاح API لنفسك، ولا ترسليهما في المحادثات.
- إذا كانت أي خدمة تشترط عمرًا معينًا لإنشاء الحساب، استعيني بولي أمرك.
